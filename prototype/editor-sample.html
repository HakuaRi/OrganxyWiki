这一版要看什么
  1. 选菜式模块化：左栏是一篮内容块，按 文本 / 结构 / 媒体 / 数据 / 高级 分组。按住块拖进中间画布，落点会显示一条亮黄绿插入线，松手即放入。这就是你说的「像选菜一样」吗？手感对不对？
  2. 空页面起步：选中 main/新页面 或点「清空」，画布就是一个空页面的虚线框，从零开始拖。要不要默认就打开空页面？
  3. 拖动排序：已放入的块也能直接拖动改顺序，拖到某个块的上下半区决定插前还是插后；也可以点块上的 上移 / 下移。
  4. 嵌套：把块拖进折叠框或侧边栏内部的虚线区，就成为它的子块；不允许把块拖进自己的子孙里（会被拒绝）。嵌套层级需要限制深度吗？
  5. 点块填参数：右栏表单完全由块的 Schema 生成，含 文本 / 多行文本 / 下拉 / 开关 / 图片 / 行列表（信息框的信息行可增删）。表单密度和字段顺序合适吗？
  6. 裸露修改接口：表单底部「高级（裸露修改）」默认折叠，里面是这个块专属的 _raw.css 与 _raw.js。
  7. 结构视图 / 成稿预览：右上角可切换。预览用的是和展示系统同一套渲染样式，所见即所得。预览要并排常显，还是这样切换就够？
  8. 高级块：篮子里最后一个是自定义 HTML，用暖色标出，属于危险块，预览中不执行、只显示源码。
  9. 这一版还没做的：GitHub 登录与真实提交（保存按钮目前只弹提示）、图片真实上传、页面列表与删除、右侧预览的滚动同步、撤销重做。哪些要优先接上？
  10. 图标：编辑器用了一套内联 SVG 图标（块类型、上移下移删除、保存、预览、上传等），不引任何外部图标库、全部跟随文字颜色。展示系统按你的要求一个图标都不加。图标风格（细线、方头、1.4 描边）可以吗？
